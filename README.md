# 🎉 Event Organization System

A PHP-based web application to manage events, bookings, and user dashboards.  
This project allows users to create, book, and manage events with a simple interface.

---

## 🚀 Features
- User authentication (login & signup)
- Create and manage events
- Book events with confirmation
- Dashboard for users and admins
- Database integration for persistent storage

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL

---

## 📂 Project Structure
├── book_event.php        # Event booking page
├── create_event.php      # Event creation page
├── dashboard.php         # User/Admin dashboard
├── db.php                # Database connection
├── login.php             # User login
├── signup.php            # User registration
└── index.php             # Homepage
